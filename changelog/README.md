# 版本更新记录

每个完整版本标签对应一个目录，中文内容保存在 `zh-CN.md`，英文内容保存在 `en-US.md`。例如 `v0.1.1` 对应 `changelog/v0.1.1/`，候选版本 `v0.2.0-rc.1` 对应 `changelog/v0.2.0-rc.1/`。

两份 Markdown 文件在推送标签前随代码提交。发布脚本读取标签所指提交中的文件，以中文、英文的顺序生成 Release 正文。文件缺失、内容为空或包含 `TODO`、`TBD`、`待填写` 时，发布检查终止。

各语言文件描述新增功能、行为调整和修复内容。内容以该版本实际包含的变更为依据，避免复制 Git 提交列表。`README.md` 提供组织规则；各版本的内容保存在对应版本目录。

更新记录参考 `example/LunaBox/CHANGELOG.md` 的分类与条目结构。中文使用 `### 新增`、`### 优化` 和 `### 修复`，英文对应 `### Added`、`### Improved` 和 `### Fixed`，每项变更使用独立的 Markdown 列表条目。分类为空时省略对应标题。

版本号由目录与 Release 标题标识。语言文件保留三级分类标题，发布脚本将中文放在以 `中文` 为摘要的默认折叠区域内，英文使用 `## English` 标题并保持展开。发布正文末尾附有与上一正式版本比较的 `Full changelog` 链接，首次发布时省略该链接。

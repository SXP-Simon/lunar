### 新增

- 新增阅读统计页面，底部导航增加「统计」入口；汇总累计阅读时长、日均阅读、阅读天数、书籍数量与已读书籍，支持按周、月、年或自定义日期范围查看，并可前后切换时段
- 新增阅读趋势图与阅读时长排行，按日或按月展示阅读时长；排行较长时可展开其余书籍
- 新增阅读日历，以色块深浅区分每日阅读时长，横向滑动回看历史；点按或长按色块查看当天的阅读详情，并可从统计页面继续阅读
- 新增阅读海报，可从统计页面按所选时段导出书单封面图；提供整图、分页和长图三种版式，支持修改标题、写一句话、选择展示的书籍、切换书名与作者显示及更换构图
- 海报支持在画布中拖动与缩放书封，提供氛围背景；可保存到相册或分享，分页导出中断后可继续保存剩余图片；缺少封面的书籍以书名展示，海报仅包含所选书籍，不含阅读原文
- 新增插件系统，底部导航增加「插件」入口；可选择或从文件管理器直接打开 `.lunar-plugin` 插件包安装，安装前展示申请的权限、签名状态与信任提示
- 新增插件仓库，可在插件设置中添加 HTTPS 仓库，确认签名密钥后浏览、安装与更新插件，并提示可更新版本及不兼容的 SDK 版本；仓库签名密钥变更时停止从该仓库获取插件
- 新增插件管理，支持启用与停用、查看运行状态与启动耗时、插件日志、插件设置和来源信息；卸载时可选择保留插件数据
- 插件可固定到底部导航，最多显示两个插件页面
- 插件可扩展阅读界面，提供工具栏按钮与阅读面板，在正文上绘制标记，读取用户交给插件的选中文字，并可向书库导入书籍
- 新增插件更新保护：新版本首次启动成功后才替换旧版本，启动失败时自动恢复；插件数据需要转换时先行备份，转换失败后恢复备份
- 新增插件安全模式，上次启动异常退出时暂停全部插件，便于逐个检查；也可手动安排下次启动进入安全模式
- 新增插件开发者模式，可安装未经已添加仓库签名验证的本地插件包，并连接 `lunar-plugin dev` 实时调试；同时提供插件 SDK 与 `lunar-plugin` 命令行工具，支持创建、构建、校验、打包、签名插件及生成仓库索引

### 优化

- 优化仿真翻页的光影效果，翻起的书页在下方页面投下柔和阴影，并加深书脊附近的明暗过渡
- 优化翻页松手判定，按实际时间计算甩动速度，使 60Hz 与 120Hz 屏幕上的翻页手感一致；手指停顿后再松开时，甩动惯性随停顿时间减弱
- 统一手势翻页与自动翻页的调度，原生翻页与界面使用同一份松手判定，改善连续翻页与不同翻页方式交替时的衔接
- 阅读内核升级至 Rito RN 0.3.1，后台排版每批处理更多页面，减少翻页时的等待；书中图片缺失或损坏时显示与当前配色协调的占位图标
